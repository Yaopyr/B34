# B34 智能小车

基于 STM32F103C8T6 的四驱智能小车项目，支持舵机云台控制、红外遥控、红外避障及自动巡游功能。

## 硬件平台

- **主控芯片**：STM32F103C8T6 (Cortex-M3, 72MHz)
- **开发环境**：Keil MDK-ARM V5
- **编译器**：ARM Compiler 5.06

## 功能模块

| 模块 | 说明 |
|------|------|
| `Servo` | 四路舵机云台控制，通过 PWM 实现 0°~180° 角度调节 |
| `Motor` | 四路直流电机驱动，支持正反转及速度调节 |
| `PWM` / `M_PWM` | 舵机与电机的底层 PWM 驱动 |
| `Drv_Hw` | 红外遥控接收解码，支持多按键识别 |
| `Irobstacle` | 左右红外避障传感器检测 |
| `OLED` | OLED 显示屏驱动 |
| `LED` | LED 指示灯控制 |
| `Key` | 板载按键输入 |
| `Delay` | 系统延时函数 |
| `EXTI` | 外部中断管理 |

## 控制逻辑

### 舵机云台

支持四路舵机独立控制，每路均设有角度限位：

| 舵机 | 角度范围 |
|------|----------|
| 舵机1 | 0° ~ 180° |
| 舵机2 | 30° ~ 180° |
| 舵机3 | 120° ~ 180° |
| 舵机4 | 0° ~ 30° |

### 红外遥控映射

| 按键 | 功能 |
|------|------|
| 1 / 4 | 舵机1 角度增减（步进 15°） |
| 2 / 5 | 舵机2 角度增减（步进 15°） |
| 3 / 6 | 舵机3 角度增减（步进 15°） |
| 8 / 0 | 舵机4 角度增减（步进 15°） |
| 11 | 启动自动巡游模式 |
| 10 | 停止自动巡游 |

### 自动巡游

进入自动巡游模式后，小车利用左右红外避障传感器实现自动避障行驶：

- 右侧检测到障碍 → 小车原地右转
- 左侧检测到障碍 → 小车原地左转
- 两侧同时检测到障碍 → 小车后退并转向

## 项目结构

```
B34sc3/
├── User/           # 用户代码
│   ├── main.c              # 主程序入口
│   ├── stm32f10x_conf.h    # 外设配置
│   └── stm32f10x_it.c/h    # 中断服务
├── Hardware/       # 硬件驱动层
│   ├── Servo.c/h           # 舵机驱动
│   ├── Motor.c/h           # 电机驱动
│   ├── PWM.c/h             # 舵机PWM
│   ├── M_PWM.c/h           # 电机PWM
│   ├── Drv_Hw.c/h          # 红外遥控接收
│   ├── Irobstacle.c/h      # 红外避障传感器
│   ├── OLED.c/h            # OLED 显示
│   ├── LED.c/h             # LED 指示灯
│   ├── Key.c/h             # 按键输入
│   └── EXTI.c/h            # 外部中断
├── System/         # 系统层
│   └── Delay.c/h           # 延时函数
├── Start/          # 启动文件
│   ├── startup_stm32f10x_md.s  # 启动汇编
│   ├── core_cm3.c/h            # CMSIS Core
│   └── system_stm32f10x.c/h    # 系统时钟配置
├── Library/        # 标准外设库
│   └── stm32f10x_*.c/h    # STM32F10x 标准外设驱动
├── Objects/        # 编译输出
└── Listings/       # 链接信息
```

## 编译与烧录

1. 使用 **Keil MDK-ARM V5** 打开 `Project.uvprojx`
2. 选择 Target `Target 1`，编译器版本 ARM Compiler 5
3. 点击 Build (F7) 编译工程
4. 通过 ST-Link / J-Link 等调试器烧录至开发板

## 依赖

- **Keil STM32F1xx DFP** 设备包（版本 2.4.1 及以上）
- **ARM Compiler 5**（ARM_Compiler_5.06u7）
